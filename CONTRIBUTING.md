# Contributing to Awesome AI Tools Directory

Thank you for your interest in contributing to the **Awesome AI Tools Directory**! 🚀

## Submission Criteria

To ensure high quality and value for the developer community, all submitted tools must:
1. Be an **authentic, operational software application, SDK, or generative AI model**.
2. **Strictly No Directories or Aggregators:** We do not list link farms, launch pads, or competing directories.
3. Have a working HTTPS landing page, clear pricing details, and documented features.

## How to Submit

### Option 1: Fast Direct Submission (Recommended)
Submit your product directly via [**NeedAITool.com/submit**](https://www.needaitool.com/submit).
- Automated screenshot capture.
- Categorization and SEO indexing within 24 hours.
- Direct inclusion in the live public directory.

### Option 2: GitHub Pull Request
1. Fork this repository.
2. Add your tool to `README.md` under the appropriate category table in alphabetical order:
   ```markdown
   | **[Tool Name](https://tool-url.com)** | Category | Pricing | Best For | [Directory Profile](https://www.needaitool.com) |
   ```
3. Submit a Pull Request with a short summary of the tool and its primary use cases.
